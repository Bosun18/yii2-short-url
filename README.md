# Сервис коротких ссылок + QR

Веб-приложение для сокращения URL-адресов с генерацией QR-кодов.
Построено на фреймворке Yii2 (Basic template).

## Возможности

- Сокращение длинных URL-адресов
- Генерация QR-кода для каждой короткой ссылки (без сторонних API)
- Валидация URL (формат и доступность ресурса)
- Редирект по короткой ссылке на оригинальный URL
- Логирование переходов (IP-адрес, время)
- Счётчик переходов по каждой ссылке
- Дедупликация — повторное сокращение того же URL возвращает существующую ссылку
- AJAX-интерфейс — всё работает без перезагрузки страницы

## Стек технологий

- **PHP** 7.4+
- **Yii2** (Basic template)
- **MySQL / MariaDB**
- **jQuery**
- **Bootstrap 5**
- **chillerlan/php-qrcode** — генерация QR-кодов на стороне сервера

## Установка и запуск

### 1. Требования

- **PHP** 7.4 или выше — [инструкция по установке](https://www.php.net/manual/ru/install.php)
- **MySQL** 5.7+ / **MariaDB** 10.3+ — [скачать MySQL](https://dev.mysql.com/downloads/mysql/)
- **Composer** — менеджер зависимостей PHP — [инструкция по установке](https://getcomposer.org/download/)
- Расширения PHP: `curl`, `gd` (для QR-кодов), `pdo_mysql`

Проверить, что всё установлено:
```bash
php -v              # версия PHP
composer --version  # версия Composer
mysql --version     # версия MySQL
php -m | grep -E "curl|gd|pdo_mysql"  # проверка расширений
```

### 2. Клонирование проекта

```bash
git clone https://github.com/Bosun18/yii2-short-url.git
cd yii2-short-url
```

### 3. Установка зависимостей

```bash
composer install
```

### 4. Создание базы данных

Откройте терминал и подключитесь к MySQL (введите пароль при запросе):

```bash
mysql -u root -p
```

Затем выполните SQL-команду:

```sql
CREATE DATABASE short_url CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Для выхода из MySQL введите `exit`.

### 5. Настройка подключения к БД

Файл `config/db.php` не входит в репозиторий (он содержит пароль). Нужно создать его из шаблона.

**macOS / Linux:**
```bash
cp config/db.php.example config/db.php
```

**Windows:**
```cmd
copy config\db.php.example config\db.php
```

Затем откройте созданный файл `config/db.php` в любом текстовом редакторе (например, Блокнот) и укажите свои данные:

```php
return [
    'class' => 'yii\db\Connection',
    'dsn' => 'mysql:host=localhost;dbname=short_url',
    'username' => 'ваш_пользователь',
    'password' => 'ваш_пароль',
    'charset' => 'utf8mb4',
];
```

### 6. Применение миграций

```bash
php yii migrate
```

При запросе подтверждения введите `yes`.

### 7. Запуск dev-сервера

```bash
php yii serve --port=8080
```

Приложение будет доступно по адресу: http://localhost:8080

## Использование

1. Откройте http://localhost:8080 в браузере
2. Вставьте длинный URL в поле ввода
3. Нажмите кнопку **OK**
4. Получите короткую ссылку и QR-код
5. Наведите камеру телефона на QR-код — откроется короткая ссылка
6. При переходе по короткой ссылке произойдёт автоматический редирект на оригинальный URL

## Проверка QR-кода с телефона

QR-код содержит короткую ссылку на основе того адреса, через который вы открыли сайт.
Если открыть сайт через `localhost` — QR будет содержать `localhost`, и телефон не сможет его открыть.
Ниже описаны три способа сделать QR-код доступным для телефона.

### Способ 1: Локальная сеть (без установки дополнительных программ)

Если компьютер и телефон подключены к **одной Wi-Fi сети**, можно открыть сайт по IP-адресу компьютера.

#### 1. Узнайте IP-адрес компьютера в локальной сети

**macOS:**
```bash
ipconfig getifaddr en0
```

**Linux:**
```bash
hostname -I | awk '{print $1}'
```

**Windows (CMD):**
```cmd
ipconfig
```
Найдите строку `IPv4-адрес` в разделе вашего Wi-Fi адаптера (обычно вида `192.168.x.x`).

#### 2. Запустите сервер, доступный в локальной сети

```bash
php -S 0.0.0.0:8080 -t web
```

> **Важно:** используйте именно `php -S 0.0.0.0:8080 -t web`, а не `php yii serve`.
> Параметр `0.0.0.0` означает, что сервер принимает подключения со всех устройств в сети,
> а не только с localhost.

#### 3. Откройте сайт по IP-адресу

Откройте в браузере на компьютере (подставьте свой IP):

```
http://192.168.x.x:8080
```

#### 4. Проверьте QR-код

1. Создайте короткую ссылку — QR будет содержать адрес вида `http://192.168.x.x:8080/AbCdEf`
2. Наведите камеру телефона на QR-код
3. Телефон откроет ссылку через локальную сеть → произойдёт редирект

> **Примечание:** этот способ работает только пока оба устройства в одной Wi-Fi сети.

---

### Способ 2: ngrok (доступ из любой сети через интернет)

Для проверки QR-кода с телефона необходимо сделать локальный сервер доступным из интернета.
Для этого используется **ngrok** — утилита, которая создаёт публичный туннель к вашему localhost.

> **Важно:** ngrok — зарубежный сервис. Для регистрации и работы может потребоваться **VPN**.

#### 1. Регистрация на ngrok

1. Перейдите на сайт: [https://ngrok.com](https://ngrok.com/)
2. Нажмите **Sign up** (правый верхний угол)
3. Зарегистрируйтесь (можно через Google/GitHub аккаунт)
4. После регистрации вы попадёте в личный кабинет (Dashboard)

#### 2. Получение authtoken

1. В личном кабинете перейдите в раздел: **Getting Started → Your Authtoken**
   (прямая ссылка: [https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken))
2. Скопируйте ваш персональный токен (длинная строка вида `2kF9x...`)

#### 3. Установка ngrok

**macOS (Homebrew):**
```bash
brew install ngrok
```

**Linux:**
```bash
curl -sSL https://ngrok-agent.s3.amazonaws.com/ngrok-v3-stable-linux-amd64.tgz | sudo tar xvz -C /usr/local/bin
```

**Windows:**
Скачайте установщик с [https://ngrok.com/download](https://ngrok.com/download) и распакуйте.

#### 4. Авторизация ngrok

Выполните команду, подставив ваш токен:

```bash
ngrok config add-authtoken ВАШ_ТОКЕН
```

#### 5. Запуск туннеля

1. Убедитесь, что dev-сервер запущен:
   ```bash
   php yii serve --port=8080
   ```

2. В **отдельном терминале** запустите ngrok:
   ```bash
   ngrok http 8080
   ```

3. ngrok выведет информацию о туннеле. Найдите строку `Forwarding` — это ваш публичный URL:
   ```
   Forwarding  https://abcdef123.ngrok-free.dev → http://localhost:8080
   ```

4. Скопируйте публичный URL (например `https://abcdef123.ngrok-free.dev`)

#### 6. Проверка QR-кода

1. Откройте **публичный URL** от ngrok в браузере на компьютере
   (при первом открытии ngrok покажет страницу с кнопкой **«Visit Site»** — нажмите её)
2. Вставьте любой URL в форму и нажмите **OK**
3. Появится QR-код, содержащий публичную короткую ссылку
4. Наведите камеру телефона на QR-код
5. Телефон предложит открыть ссылку — нажмите на неё
6. Произойдёт редирект на оригинальный сайт

> **Примечание:** на бесплатном плане ngrok публичный URL меняется при каждом перезапуске.
> QR-коды, созданные с предыдущим URL, перестанут работать после перезапуска ngrok.

### Способ 3: Деплой на бесплатный хостинг (InfinityFree)

Проект можно разместить на бесплатном PHP-хостинге **InfinityFree**, чтобы он был доступен
из интернета без ngrok и без локальной сети. QR-код будет содержать публичный URL,
доступный с любого устройства.

#### Плюсы
- Бесплатно и без ограничения по времени
- Поддержка PHP + MySQL из коробки
- Бесплатный поддомен (например `yoursite.infinityfreeapp.com`)
- QR-код работает с любого устройства из любой сети
- Не нужен VPN (в отличие от ngrok)
- Можно сразу открыть ссылку — ничего не нужно разворачивать

#### Минусы
- Нет SSH-доступа — нельзя запустить `composer install` и `php yii migrate` на сервере
- Папку `vendor/` нужно загружать вместе с проектом (через FTP или файловый менеджер)
- Миграции нужно применить локально и экспортировать SQL-дамп, затем импортировать через phpMyAdmin
- Медленнее, чем локальный сервер
- Иногда показывает рекламу на бесплатном плане
- Ограничение на размер файлов и количество запросов

#### Пошаговая инструкция

##### 1. Регистрация

1. Перейдите на сайт: https://www.infinityfree.com/
2. Нажмите **Sign Up** и зарегистрируйтесь
3. После регистрации войдите в панель управления

##### 2. Создание аккаунта хостинга

1. В панели управления нажмите **Create Account**
2. Выберите бесплатный поддомен (например `shorturl.infinityfreeapp.com`) или подключите свой домен
3. Запомните выданные данные: **имя пользователя**, **пароль** и **адрес FTP-сервера**

##### 3. Создание базы данных

1. В панели управления перейдите в раздел **MySQL Databases**
2. Создайте новую базу данных — запомните:
   - Имя базы данных
   - Имя пользователя БД
   - Пароль БД
   - Хост БД (обычно вида `sqlXXX.infinityfree.com`)

##### 4. Импорт структуры БД

Так как на бесплатном хостинге нет SSH, миграции нужно применить через phpMyAdmin:

1. Сначала **локально** экспортируйте структуру БД:
   ```bash
   mysqldump -u root -p --no-data short_url > short_url_structure.sql
   ```
2. В панели управления хостинга откройте **phpMyAdmin**
3. Выберите вашу базу данных
4. Перейдите на вкладку **Import**
5. Загрузите файл `short_url_structure.sql` и нажмите **Go**

##### 5. Настройка подключения к БД

Перед загрузкой файлов отредактируйте `config/db.php`, указав данные от хостинга:

```php
return [
    'class' => 'yii\db\Connection',
    'dsn' => 'mysql:host=sqlXXX.infinityfree.com;dbname=ИМЯ_БАЗЫ',
    'username' => 'ПОЛЬЗОВАТЕЛЬ_БД',
    'password' => 'ПАРОЛЬ_БД',
    'charset' => 'utf8mb4',
];
```

##### 6. Загрузка файлов на хостинг

Загрузите **все файлы проекта** (включая папку `vendor/`) на хостинг через FTP-клиент
(например [FileZilla](https://filezilla-project.org/)):

1. Подключитесь к FTP-серверу, используя данные из шага 2
2. Перейдите в папку `htdocs/` на сервере
3. Содержимое папки `web/` вашего проекта загрузите в корень `htdocs/`
4. Остальные папки проекта (`controllers/`, `models/`, `config/`, `vendor/` и т.д.)
   загрузите на один уровень выше `htdocs/` или в `htdocs/` рядом — и поправьте пути
   в `index.php` при необходимости

Рекомендуемая структура на сервере:
```
/                          ← корень аккаунта
├── config/
├── controllers/
├── models/
├── vendor/
├── views/
├── runtime/
└── htdocs/                ← публичная папка (сюда содержимое web/)
    ├── index.php
    ├── assets/
    ├── css/
    └── .htaccess
```

##### 7. Проверка

1. Откройте ваш поддомен в браузере: `https://yoursite.infinityfreeapp.com`
2. Создайте короткую ссылку — QR будет содержать публичный URL
3. Наведите камеру телефона на QR-код — ссылка откроется из любой сети
